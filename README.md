## Overview

Sapphire Game Engine is a passion project aimed at providing a simple yet powerful foundation for building 2D games. It focuses on ease of use, clear architecture, and extensibility, allowing developers to quickly bring their ideas to life without getting bogged down in complex systems.

**Key Features:**

* **Intuitive Scene Management:** Organize your game world with a hierarchical scene graph.
* **Flexible Entity-Component System (ECS):** Design game logic with reusable components and efficient data management.
* **Built-in Rendering:** Supports sprite rendering, basic shapes, and tilemaps out of the box.
* **Input Handling:** Easily manage keyboard, mouse, and gamepad input.
* **Basic Physics:** Includes a lightweight 2D physics system for collisions and basic interactions.
* **Audio Support:** Play sound effects and background music.
* **Extensible Architecture:** Designed to be easily extended with custom systems and features.
* **Scripting Support (Optional):** Integrate with scripting languages (e.g., Lua, Python) for dynamic game logic.
* **Cross-Platform Potential:** Architected with portability in mind (current support may vary).
